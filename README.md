# 🗺️ Mapas — Localización Geodésica por Multilateración & Mapas Offline (PWA)

Aplicación Web Progresiva (**PWA**) especializada en geolocalización, cartografía interactiva y cálculo de posición de alta precisión mediante algoritmos no lineales de **trilateración y multilateración geodésica**, con soporte completo para almacenamiento de teselas y mapas offline.

---

## ✨ Características Principales

- 📍 **Algoritmos Geodésicos de Trilateración & Multilateración:** Estimación de coordenadas geográficas en base a distancias o señales desde múltiples puntos de referencia fijos (balizas, torres celulares o puntos de control).
- 📶 **Soporte Offline Completo (PWA):** Service Workers y almacenamiento en caché para visualización cartográfica sin conexión a internet.
- 🗺️ **Mapas Interactivos:** Representación gráfica de radios de alcance, áreas de intersección geométrica, círculos de error y coordenadas estimadas sobre mapas satelitales y vectoriales.
- 📱 **Instalable & Multiplataforma:** Compatible con navegadores móviles, escritorios y tablets con experiencia de aplicación nativa.

---

## 🛠️ Tecnologías

- **Frontend:** HTML5, CSS3 moderno, JavaScript ES6+ / TypeScript
- **Cartografía:** Leaflet / OpenStreetMap / MapLibre GL
- **Estándares Web:** Progressive Web App (PWA), Service Workers, Cache Storage API, IndexedDB
